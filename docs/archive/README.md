# ארכיון

`standalone-original.html` — הכלי לפני העיצוב מחדש: קובץ יחיד שהכיל את הכול,
HTML, CSS, המנוע והממשק. הוא הוחלף ב-PR #1 בפיצול הנוכחי (`index.html` עם
`support.js` ו-`redact-engine.js`), ואינו רץ ואינו נתמך.

הוא נשמר כאן מפני שזה העותק היחיד: הוא מעולם לא נכנס להיסטוריית ה-git, בניגוד
לכל שאר קבצי ההעברה המקוריים. אין להעתיק ממנו קוד — המנוע התקדם מאז בעשרות
תיקונים שמתועדים ב-CHANGELOG וב-docs/measurements.md.
