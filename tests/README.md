# סוללות הבדיקה

12 סוללות, 225 קביעות. נכתבו מול הגרסה הוונילה: כל אחת מחלצת את
המנוע מ-`app.html` דרך `extract.py`. **צריך להתאים אותן לייבא את
המנוע של ה-repo ישירות**, ולחבר ל-`npm test`.

| קובץ | מה נבדק | קביעות |
|---|---|---|
| `t.js` | סורק שיבושים, שמות בדויים, החזרה | 44 |
| `e2e.js` | הצינור המלא על docx שנבנה בקוד | 25 |
| `edge.js` | שמות שהם גם מילים, גופים, תארים, כתיב כפול, ניקוד, שם משולש, התנגשות פרופיל | 33 |
| `ner_t.js` | ניקוי פלט המודל, תיקון קיצוץ, קילוף אות שימוש | 26 |
| `flow.js` | חיווט הממשק, מסך "מי בתיק", נפילה רכה | 26 |
| `tok_t.js` | תיקון ה-JSON של הטוקנייזר, כותרות תגובה | 18 |
| `theme_t.js` | טוקני עיצוב, מצב כהה | 13 |
| `align_t.js` | יישור טוקנים, קיבוץ B/I, חלוקה לקטעים | 12 |
| `diag_t.js` | הכנת הטוקנייזר, מטמון, מסלולי כשל | 10 |
| `org_t.js` | סוג "גוף" מקצה לקצה | 7 |
| `race_t.js` | מרוצים בין הסריקה למשתמשת | 6 |
| `case.js` | אותם שמות בדויים בשני מסמכים באותו תיק | 5 |

`ui.js` בודק נוכחות אלמנטים. `gap.js`, `real.js`, `perf.js` הם
כלי מדידה ולא בדיקות — הם מדפיסים דוח, לא ציון.

`mkzip.js` בונה docx בזיכרון. `protocol.txt` הוא תמלול ועדת כנסת
אמיתי, ובו שיבוש תמלול אותנטי: אותה אישה מופיעה כ"שלוה ליבוביץ"
וכ"שלווה". זה המקרה שהכלי קיים בשבילו — לא להחליף אותו בפיקטורה.

**לא לכתוב מחדש.** כמה מהקביעות מקודדות באגים שלקח זמן למצוא:
`race_t.js` תופס דליפת שמות בין תיקים, `tok_t.js` תופס כותרות
תגובה שמחזירות JSON שבור, ו-`edge.js` תופס שם משפחה שנשאר בטקסט
כשהשם המלא לא מופיע במסמך.
