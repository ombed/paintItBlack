# הבדיקות

`npm test` מריץ שני חצאים: סוללות Node (`tests/run.js`) ואחריהן בדיקות
דפדפן (`e2e/`, Playwright על Chromium). שניהם רצים על כל PR ב-CI.

## סוללות Node

`tests/build-fixtures.js` בונה מ-`redact-engine.js` את `app.html` ו-`core.js`
שהסוללות מצפות להם (הן נכתבו מול גרסה וונילה בקובץ אחד), ואז
`tests/run.js` מריץ את הרשימה. המנוע הנבדק הוא תמיד זה שב-repo.

| קובץ | מה נבדק |
|---|---|
| `t.js` | סורק שיבושים, שמות בדויים, החזרה |
| `e2e.js` | הצינור המלא על docx שנבנה בקוד |
| `edge.js` | שמות שהם גם מילים, גופים, תארים, כתיב כפול, ניקוד, שם משולש, התנגשות פרופיל |
| `ner_t.js` | ניקוי פלט המודל, תיקון קיצוץ, קילוף אות שימוש |
| `tok_t.js` | תיקון ה-JSON של הטוקנייזר, כותרות תגובה |
| `align_t.js` | יישור טוקנים, קיבוץ B/I, חלוקה לקטעים |
| `diag_t.js` | הכנת הטוקנייזר, מטמון, מסלולי כשל |
| `org_t.js` | סוג "גוף" מקצה לקצה |
| `case.js` | אותם שמות בדויים בשני מסמכים באותו תיק |
| `version_t.js` | ששת אתרי הגרסה מסכימים |
| `design_t.js` | קובץ הקנבס נגזר מ-`index.html` ולא התיישן |

ארבע סוללות (`flow.js`, `theme_t.js`, `race_t.js`, `ui.js`) נכתבו מול
ממשק וונילה עם מזהי אלמנטים שאין כאן. הן נשארות כתיעוד של מה שנבדק,
והכוונה שלהן הועברה ל-`e2e/`.

**לא לכתוב מחדש את סוללות המנוע.** כמה מהקביעות מקודדות באגים שלקח זמן
למצוא: `race_t.js` תופס דליפת שמות בין תיקים, `tok_t.js` תופס כותרות
תגובה שבורות מהטוקנייזר, `edge.js` תופס שם שהוא גם מילה.

`mkzip.js` בונה docx בזיכרון. `protocol.txt` הוא תמלול ועדת כנסת
אמיתי, ובו שיבוש תמלול אותנטי: אותה אישה מופיעה כ"שלוה ליבוביץ"
וכ"שלווה". זה המקרה שהכלי קיים בשבילו.

## כלי מדידה (לא ציון)

`npm run report` מריץ את `gap.js`, `real.js` ו-`perf.js`: דוח פערים, התמלול
האמיתי עם שורת PASS/FAIL, וזמני ריצה. `npm run bench` הוא הבנצ'מרק על
הקורפוס הסינתטי (ראו `bench/README.md`); `npm run bench:nomodel` הגרסה
הדטרמיניסטית שרצה ב-CI, ו-`npm run gate` משווה אותה למצב הבסיס.

## בדיקות דפדפן

| קובץ | מה נבדק |
|---|---|
| `render.spec.js` | הדף עולה בלי שגיאות, אין `{{ }}`, הדף ועובד השירות באותה גרסה |
| `model.spec.js` | מסלול המודל דרך stub, שורת הקונסול |
| `race.spec.js` | החלפת מסמך באמצע סריקה; הכפתור נעול בזמן סריקה |
| `theme.spec.js` | מצב לילה, טוקני צבע |
| `ui.spec.js` | כל מסך מציג את הפקדים שלו |
| `flow.spec.js` | מילוי מהכותרת, עריכת הרשימה, נפילה רכה של המודל |
| `speakers.spec.js` | תורות דיבור בתמלול ממלאים את הרשימה |
| `also-found.spec.js` | רצועת "נמצאו גם" |
| `undo.spec.js` | "לא שם" מחזיר את המשפט; שני מקטעים פתוחים יחד |

`e2e/helpers.js` מגיש את המנוע עם המודל מדומה (`window.__ner`) ובונה docx
בתוך הדף. `.audit.spec.js` הוא מעבר צילומים לביקורות UX, רץ רק עם
`AUDIT=1`.
